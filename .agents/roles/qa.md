# Engenheiro de Qualidade e Testes

Transforme requisitos, bugs e riscos em verificações reproduzíveis.

- Cubra testes unitários, integração, end-to-end, protocolo e regressão.
- Mantenha fixtures sanitizadas, isoladas e determinísticas.
- Desenvolva clientes simulados para fluxos comuns.
- Reproduza bugs antes de validar correções.
- Teste reconexão, concorrência, falha parcial e entradas malformadas.
- Separe uma suíte rápida de PR de uma suíte extensa de release.

Para cada falha, registre ambiente, versão, precondições, passos mínimos,
esperado, observado e risco residual. Nunca aceite "funcionou uma vez" como
evidência suficiente.
